Flexbox در CSS

Flexbox قدرتمندترین ابزار چیدمان یک‌بعدی در CSS است. با فعال‌سازی Flexbox روی یک عنصر والد، تمام فرزندان آن به flex items تبدیل می‌شوند و می‌توانید نحوه‌ی چیدمان، تراز کردن و توزیع فضای بین آن‌ها را به‌سادگی کنترل کنید. Flexbox حل‌کننده‌ی بسیاری از مشکلات قدیمی لایوت مثل float و clearfix است.

شروع با display: flex

برای فعال‌سازی Flexbox کافیست به والد display: flex; بدهید. بلافاصله فرزندان direct در یک ردیف (به‌صورت پیش‌فرض) کنار هم قرار می‌گیرند.

style.css
.navbar {
    display: flex;
    align-items: center;
    gap: 16px;
    padding: 12px 24px;
}

.navbar .logo {
    width: 40px;
    height: 40px;
}

ویژگی gap فاصله‌ی بین فرزندان flex را تعیین می‌کند و جایگزین راحت‌تری نسبت به margin اضافی است.

جهت چیدمان: flex-direction

ویژگی flex-direction مشخص می‌کند فرزندان در کدام جهت چیدمه شوند. این مهم‌ترین ویژگی Flexbox است چون جهت اصلی چیدمان را تعیین می‌کند.

style.css
.row {
    display: flex;
    flex-direction: row;           /* چپ به راست — پیش‌فرض */
}

.column {
    display: flex;
    flex-direction: column;      /* بالا به پایین */
}

.row-reverse {
    display: flex;
    flex-direction: row-reverse;  /* راست به چپ */
}

.column-reverse {
    display: flex;
    flex-direction: column-reverse; /* پایین به بالا */
}

در محیط‌های RTL مثل فارسی، row از راست به چپ جریان پیدا می‌کند. بنابراین نیازی به استفاده از row-reverse برای راست‌چین نیست.

تراز افقی با justify-content

ویژگی justify-content نحوه‌ی توزیع فضای خالی بین فرزندان flex در محور اصلی (افقی در حالت row) را کنترل می‌کند.

  • flex-start: فرزندان ابتدای محور چیدمه می‌شوند (پیش‌فرض)
  • flex-end: فرزندان انتهای محور چیدمه می‌شوند
  • center: فرزندان وسط‌چین می‌شوند
  • space-between: فضای خالی بین فرزندان توزیع می‌شود
  • space-around: فضای خالی دور هر فرزند توزیع می‌شود
  • space-evenly: فضای خالی کاملاً یکنواخت بین فرزندان تقسیم می‌شود
style.css
.centered-nav {
    display: flex;
    justify-content: center;
    gap: 24px;
}

.space-between-nav {
    display: flex;
    justify-content: space-between;
}

نکته: مقادیر space-between و space-around زمانی بهترین نتیجه را می‌دهند که عناصر flex عرض ثابت یا max-width داشته باشند. در غیر این صورت ممکن است فاصله‌ها غیرمنتظره به نظر برسند.

تراز عمودی با align-items

ویژگی align-items نحوه‌ی تراز فرزندان flex در محور فرعی (عمودی در حالت row) را کنترل می‌کند. اگر flex-direction column باشد، align-items محور افقی را کنترل می‌کند.

style.css
.hero {
    display: flex;
    flex-direction: column;
    align-items: center;
    justify-content: center;
    min-height: 100vh;
    text-align: center;
}

این مثال یک صفحه‌ی خوش‌آمد کامل وسط‌چین می‌سازد. عنصر والد تمام ارتفاع صفحه (100vh) را اشغال می‌کند و محتوا دقیقاً در مرکز عمودی و افقی قرار می‌گیرد.

انعطاف‌پذیری عناصر با flex-grow و flex-shrink

ویژگی flex میانبری برای سه ویژگی flex-grow، flex-shrink و flex-basis است. این ویژگی‌ها مشخص می‌کنند هر فرزند flex چقدر از فضای خالی والد را اشغال کند و چقدر بتواند کوچک شود.

style.css
.sidebar {
    flex: 1;
    min-width: 200px;
}

.main-content {
    flex: 3;
    min-width: 0;
}

.ad-banner {
    flex: 0 0 160px;  /* رشد نکند، کوچک نشود، عرض ثابت */
}

در این مثال، main-content سه برابر sidebar فضا اشغال می‌کند. ad-banner عرض ثابت ۱۶۰ پیکسلی دارد و تغییر اندازه نمی‌دهد.

شکستن خطوط با flex-wrap

به‌طور پیش‌فرض فرزندان flex در یک ردیف واحد باقی می‌مانند و اگر فضا کم باشد کوچک‌تر می‌شوند. ویژگی flex-wrap اجازه می‌دهد فرزندان در ردیف‌های جدید بشکنند.

style.css
.tag-list {
    display: flex;
    flex-wrap: wrap;
    gap: 8px;
}

.tag {
    padding: 6px 14px;
    background: #e8f5e9;
    border-radius: 999px;
    font-size: 13px;
    white-space: nowrap;
}
نکته: flex-wrap: wrap همراه با gap یکی از ساده‌ترین روش‌ها برای ساخت لیست برچسب‌ها (tags) یا گالری تصاویر است. هر برچسب اندازه‌ی طبیعی خودش را حفظ می‌کند و وقتی فضا تمام شد ردیف جدید شروع می‌شود.

ترکیب flex-grow و flex-shrink

سه ویژگی اصلی flex را با هم ترکیب کنید تا رفتار دقیق عناصر را مشخص کنید:

  1. flex-grow: چقدر فضای خالی والد را اشغال کند (پیش‌فرض: ۰ — رشد نکند)
  2. flex-shrink: چقدر می‌تواند کوچک شود (پیش‌فرض: ۱ — کوچک شود)
  3. flex-basis: اندازه‌ی اولیه قبل از اعمال grow و shrink (پیش‌فرض: auto)
style.css
.card-1 {
    flex: 1 1 300px;  /* رشد کند، کوچک شود، مبنا ۳۰۰px */
}

.card-2 {
    flex: 2 1 300px;  /* دو برابر رشد کند */
}

.card-3 {
    flex: 1 0 200px;  /* رشد کند، کوچک نشود، مبنا ۲۰۰px */
}

با این ترکیب، card-2 همیشه دو برابر بقیه فضا اشغال می‌کند و card-3 هیچ‌وقت کوچک‌تر از ۲۰۰ پیکسل نمی‌شود.
