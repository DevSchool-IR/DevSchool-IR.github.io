Pseudo-Classes در CSS

تا اینجای دوره همیشه عناصر را با selectors معمولی انتخاب کردیم. اما خیلی از انتخاب‌ها به «حالت» یا «موقعیت» عنصر وابسته است: وقتی ماوس روی لینک است، وقتی یک input فوکوس دارد، یا وقتی یک ردیف در جدول زوج است. Pseudo-Classes دقیقاً برای این مواقع ساخته شده‌اند.

Pseudo-Class چیست؟

یک pseudo-class با علامت : به یک selector اضافه می‌شود و عنصر را فقط زمانی انتخاب می‌کند که حالت خاصی داشته باشد. بر خلاف selectors معمولی، pseudo-class به «حالت» یا «ترتیب» عنصر نگاه می‌کند، نه فقط به نام یا کلاسش.

style.css
a:hover {
    color: #04aa6d;
}

input:focus {
    outline: 2px solid #04aa6d;
}

این یعنی: لینک‌ها فقط وقتی ماوس رویشان است سبز شوند و inputها فقط وقتی فوکوس دارند دورشان خط سبز باشد. بدون یک خط جاوااسکریپت.

حالت‌های تعاملی: hover، active و focus

سه pseudo-class متعلق به تعامل مستقیم کاربر با عنصر است که بیشترین استفاده را دارند:

  • :hover — وقتی نشانگر ماوس روی عنصر است
  • :focus — وقتی عنصر فوکوس دارد (کلیک یا کلید Tab)
  • :active — در لحظه‌ی کلیک کردن (قبل از رها کردن)
style.css
button {
    background-color: #eeeeee;
    border: none;
    padding: 10px 24px;
    border-radius: 8px;
    cursor: pointer;
}

button:hover {
    background-color: #cfd8dc;
}

button:active {
    background-color: #90a4ae;
}

با این سه حالت، دکمه هنگام hover کمی تیره و هنگام کلیک تیره‌تر می‌شود. این بازخورد بصری باعث می‌شود رابط کاربری زنده‌تر و خوش‌دست‌تر به نظر برسد.

استایل دادن به لینک‌ها

برای لینک‌ها دو pseudo-class مخصوص دیگر هم داریم: :link برای لینک‌هایی که هنوز باز نشده‌اند و :visited برای لینک‌هایی که کاربر قبلاً دیده است.

style.css
a {
    color: #1565c0;
    text-decoration: none;
}

a:hover {
    color: #0d47a1;
    text-decoration: underline;
}

a:visited {
    color: #6a1b9a;
}
نکته: برای state های لینک ترتیب استاندارد LVHA را رعایت کنید: :link، سپس :visited، سپس :hover و بعد :active. چون CSS بر اساس ترتیب عمل می‌کند، اگر :hover را قبل از :visited بنویسید، روی لینک‌های دیده‌شده hover کار نخواهد کرد.

انتخاب فرزندان اول و آخر

با :first-child و :last-child می‌توانید اولین و آخرین فرزند یک والد را انتخاب کنید. این الگو برای حذف border اضافی یا برجسته کردن آیتم اول بسیار مفید است.

style.css
.menu li:first-child {
    font-weight: 700;
}

.menu li:last-child {
    border-bottom: none;
}

اگر هر آیتم منو border پایین داشته باشد، با :last-child می‌توانید آخرین آيتم را بدون خط نمایش دهید — بدون اینکه کلاسی به HTML اضافه کنید.

الگوها با nth-child

:nth-child() قدرتمندتر است؛ هر الگوی عددی را می‌پذیرد: عدد ثابت، کلمه‌ی odd/even یا فرمول‌هایی مثل 3n+1. رایج‌ترین کاربرد آن، ردیف‌های «گورخری» جدول است.

style.css
.table tbody tr:nth-child(even) {
    background-color: #f1f8e9;
}

.table tbody tr:hover {
    background-color: #e0f2f1;
}

ردیف‌های زوج سبز روشن می‌شوند و با hover کمی تغییر رنگ می‌دهند. ترکیب nth-child(3n) هم برای انتخاب هر سومین آیتم رایج است.

نفی کردن با :not

با :not() می‌توانید همه‌ی عناصری را انتخاب کنید که با یک selector مشخص مطابقت ندارند. این برای «همه به‌جز…» عالی است.

style.css
.menu li:not(:last-child) {
    border-bottom: 1px solid #cfd8dc;
}

input:not(:read-only) {
    background-color: #fffbff;
}
نکته: داخل :not() می‌توانید pseudo-class دیگری هم بگذارید (مثل :not(:last-child)). فقط به یاد داشته باشید :not() خودش به اندازه‌ی specificity محتوای درونش را اضافه می‌کند؛ پس در پروژه‌های بزرگ، بیش از حد از آن برای overriding استفاده نکنید.
