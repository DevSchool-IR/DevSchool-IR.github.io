Opacity در CSS

گاهی لازم است یک عنصر را نیمه‌شفاف نشان دهید: تصویری که محو شده، لایه‌ای تیره روی عکس، یا دکمه‌ای که هنگام غیرفعال بودن کمرنگ است. ویژگی opacity شفافیت کل یک عنصر را از ۰ (کاملاً نامرئی) تا ۱ (کاملاً شفاف ناپذیر) کنترل می‌کند.

مقدار دهی opacity

مقدار opacity می‌تواند عددی بین ۰ و ۱ باشد. مقدار ۱ یعنی کاملاً مات (پیش‌فرض)، مقدار ۰ یعنی کاملاً نامرئی و مقادیر بین آن‌ها مثلاً 0.5 یعنی نیمه‌شفاف. نکته‌ی مهم: opacity روی کل عنصر و همه‌ی فرزندانش اعمال می‌شود، نه فقط پس‌زمینه.

style.css
.dimmed-box {
    opacity: 0.4;
    background-color: #263238;
    color: #ffffff;
}

تمام محتوای داخل باکس — متن، تصویر و پس‌زمینه — با هم ۴۰ درصد شفاف می‌شوند. فکر کنید یک لایه‌ی شیشه‌ای روی آن کشیده‌اند. این رفتار با رنگ‌های شفاف فرق دارد؛ آنجا فقط یک رنگِ مشخص شفاف می‌شود.

تفاوت با visibility و display

سه روش برای «پنهان کردن» عنصر وجود دارد و نتیجه‌های آن‌ها یکی نیست:

  1. opacity: 0; — عنصر نامرئی می‌شود اما فضای خودش را اشغال می‌کند و کلیک‌پذیر می‌ماند و همچنان قابل انیمیت است.
  2. visibility: hidden; — عنصر نامرئی است و فضایش می‌ماند، اما کلیک و رویدادها را دریافت نمی‌کند.
  3. display: none; — عنصر کاملاً از صفحه حذف می‌شود؛ هیچ فضایی نمی‌گیرد و هیچ رویدادی نمی‌گیرد. برای انیمیت هم قابلیت ندارد.

برای افکت‌های محو و fade، opacity بهترین گزینه است چون با transition و animation ترکیب می‌شود. اما اگر فقط می‌خواهید چیزی از دسترس کاربر خارج شود، display: none مناسب‌تر است.

جایگزین بهتر: رنگ‌های شفاف rgba

اگر فقط می‌خواهید پس‌زمینه شفاف باشد نه متن و تصویر داخلش، به‌جای opacity از رنگ‌های با کانال آلفا مثل rgba() استفاده کنید. یک مثال معروف: پس‌زمینه‌ی تیره‌ی نیمه‌شفاف روی کل صفحه برای مودال.

style.css
.modal-backdrop {
    background-color: rgba(0, 0, 0, 0.6);
    position: fixed;
    inset: 0;
    z-index: 50;
}

این لایه فقط پس‌زمینه‌ی سیاه ۶۰٪ شفاف دارد؛ هر عنصر سفید روی آن، همچنان کاملاً مات و خوانا دیده می‌شود.

یک کاربرد رایج دیگر: با hover شفافیت تصویر را کم کنید تا متنِ روی آن دیده شود:

style.css
.media-card {
    opacity: 1;
    transition: opacity 250ms ease;
}

.media-card:hover {
    opacity: 0.7;
}
نکته: وقتی opacity یک عنصر کمتر از ۱ باشد، آن عنصر یک stacking context جدید می‌سازد (همان مفهومی که در فصل Z-Index دیدید). یعنی z-index فرزندانش دیگر نسبت به عناصر بیرون مقایسه نمی‌شوند. در نتیجه گاهی ناگهان لایه‌بندی صفحه تغییر می‌کند؛ این رفتار طبیعی است.
