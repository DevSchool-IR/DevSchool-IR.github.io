Float و Clear در CSS

قبل از ظهور Flexbox و Grid، توسعه‌دهندگان وب برای چیدمان صفحات از ویژگی float استفاده می‌کردند. float در اصل برای چیدن عناصر متنی کنار تصاویر طراحی شده بود، اما به‌سرعت تبدیل به ابزار اصلی لایوت‌بندی صفحات شد. امروزه با وجود Flexbox و Grid کاربرد float کمتر شده اما هنوز در بعضی سناریوها مفید است.

  • float: left; عنصر را به سمت چپ جابه‌جا می‌کند
  • float: right; عنصر را به سمت راست جابه‌جا می‌کند
  • float: none; رفتار پیش‌فرض — بدون شناور شدن

شناور کردن عناصر با float

وقتی به یک عنصر float بدهید، آن عنصر از جریان عادی صفحه خارج می‌شود (مثل absolute اما متفاوت) و به سمت مشخص‌شده جابه‌جا می‌شود. عناصر متنی اطراف آن دورش جریان پیدا می‌کنند. این دقیقاً همان رفتاری است که وقتی در یک سند Word تصویری را کنار متن قرار می‌دهید مشاهده می‌کنید.

style.css
.article-thumb {
    float: left;
    width: 200px;
    height: 150px;
    margin-left: 0;
    margin-bottom: 12px;
    margin-right: 20px;
    object-fit: cover;
}

نکته‌ی مهم: وقتی یک عنصر شناور می‌شود، عناصر block اطرافش (مثل <div> و <p>) همچنان کل عرض را اشغال می‌کنند و فقط عناصر inline (مثل متن) دور آن جریان پیدا می‌کنند.

جلوگیری از تأثیر float با clear

وقتی یک عنصر شناور می‌شود، ممکن است عناصر بعدی در صفحه رفتار عجیبی نشان دهند. مثلاً یک باکس بعد از عنصر شناور ممکن است بالا بیاید و زیر عنصر شناور قرار بگیرد. ویژگی clear این مشکل را حل می‌کند و مشخص می‌کند عنصر بعدی نباید شناورهای قبلی را در سمت خاصی بپذیرد.

style.css
.footer {
    clear: both;
    padding: 20px 0;
    text-align: center;
}

مقادیر clear:

  • clear: left; — جلوی شناورهای چپ را می‌گیرد
  • clear: right; — جلوی شناورهای راست را می‌گیرد
  • clear: both; — جلوی هر دو نوع شناور را می‌گیرد (رایج‌ترین مقدار)
  • clear: none; — رفتار پیش‌فرض، بدون محدودیت

تکنیکclearfix

یکی از مشکلات رایج float این است که والد عنصر شناور ارتفاعش صفر می‌شود. چون فرزند شناور از جریان صفحه خارج شده، والد فکر می‌کند فرزندی ندارد و ارتفاعش را تنظیم نمی‌کند. این باعث می‌شود عناصر بعدی بالا بیایند و طراحی به هم بریزد.

تکنیک clearfix یک راه‌حل ساده برای این مشکل است. با اضافه کردن یک عنصر خالی با clear: both بعد از عناصر شناور، والد مجبور می‌شود ارتفاع فرزندان شناور را در نظر بگیرد.

index.html
<!-- روش قدیمی clearfix -->
<div class="container">
    <div class="float-left">ستون چپ</div>
    <div class="float-right">ستون راست</div>
    <div class="clearfix"></div>
</div>
style.css
.clearfix {
    clear: both;
}

.float-left {
    float: left;
    width: 48%;
}

.float-right {
    float: right;
    width: 48%;
}

روش مدرن‌تر clearfix با ::after پس‌الemennt انجام می‌شود که نیازی به عنصر خالی اضافی در HTML ندارد. این تکنیک در فصل Pseudo-Elements توضیح داده خواهد شد.

چیدمان دو ستونی با float

قبل از Flexbox، رایج‌ترین روش ساخت چیدمان دو ستونی (سایدبار + محتوا) با float بود. یک ستون به چپ و دیگری به راست شناور می‌شد و متن دورشان جریان پیدا می‌کرد.

style.css
.sidebar {
    float: left;
    width: 25%;
    background-color: #eceff1;
    padding: 20px;
}

.main-content {
    float: right;
    width: 73%;
    padding: 20px;
}

اگرچه float هنوز کار می‌کند، برای چیدمان‌های پیچیده امروزی استفاده از Flexbox (فصل ۲۴) و CSS Grid (فصل ۲۵) بسیار ساده‌تر و قابل اتکاتر است.
