سرریز محتوا در CSS

تصور کنید یک باکس با عرض و ارتفاع ثابت دارید و محتوای داخل آن آنقدر زیاد است که از ابعاد باکس بیرون می‌زند. مثلاً یک متن طولانی در یک کارت کوچک، یا یک تصویر بزرگ در یک ناحیه‌ی محدود. ویژگی overflow مشخص می‌کند محتوای اضافی چه رفتاری داشته باشد: آیا دیده شود؟ مخفی شود؟ اسکرول‌بار اضافه شود؟

مقدار visible: رفتار پیش‌فرض

مقدار پیش‌فرض ویژگی overflow برابر با visible است. یعنی اگر هیچ مقداری تعریف نکنید، محتوایی که از عناصر بیرون بزند به‌صورت عادی نمایش داده می‌شود و هیچ بخشی از آن مخفی نمی‌شود. محتوا به‌سادگی روی عناصر دیگر قرار می‌گیرد.

style.css
.alert-box {
    width: 200px;
    height: 80px;
    overflow: visible;
    background-color: #fff3e0;
    border: 1px solid #ff9800;
}

اگر متن داخل alert-box بیشتر از فضای موجود باشد، محتوا از پایین باکس بیرون می‌زند و زیر عناصر دیگر صفحه قرار می‌گیرد. این رفتار ممکن است طراحی صفحه را به هم بریزد.

مقدار hidden: مخفی کردن محتوا

مقدار hidden تمام محتوایی که از ابعاد عنصر بیرون بزند را به‌طور کامل مخفی می‌کند. هیچ اسکرول‌باری اضافه نمی‌شود و کاربر هیچ راهی برای دیدن محتوای پنهان ندارد.

style.css
.avatar-wrapper {
    width: 120px;
    height: 120px;
    overflow: hidden;
    border-radius: 50%;
}

استفاده‌ی رایج hidden: ساخت آواتار دایره‌ای. باکس با border-radius: 50% دایره‌ای می‌شود و overflow: hidden تضمین می‌کند هر بخشی از تصویر که از دایره بیرون بزند مخفی شود. همچنین hidden به‌عنوان والد مرجع برای عناصر absolute فرزند عمل می‌کند و مانع خروج آن‌ها از والد می‌شود.

مقادیر scroll و auto

مقدار scroll وقتی محتوا از ابعاد عنصر بیرون بزند، اسکرول‌بار اضافه می‌کند. نکته‌ی مهم: اسکرول‌بار همیشه نمایش داده می‌شود، حتی اگر محتوا از حد تجاوز نکرده باشد. مقدار auto تقریباً مثل scroll است اما اسکرول‌بار فقط وقتی ظاهر می‌شود که واقعاً محتوا اضافه باشد. این دقیقاً همان رفتاری است که اکثر مواقع به آن نیاز دارید.

style.css
.comment-box {
    width: 100%;
    max-height: 150px;
    overflow: auto;
    border: 1px solid #cfd8dc;
    padding: 12px;
    line-height: 1.8;
}
نکته: در بسیاری از پروژه‌ها، به‌جای overflow: scroll; از overflow: auto; استفاده می‌شود. دلیل آن رفتار هوشمندانه‌ی auto است که فقط در صورت نیاز اسکرول‌بار نشان می‌دهد. همچنین استفاده از max-height به‌جای height باعث می‌شود باکس در صورت کم بودن محتوا کوچک‌تر شود و اسکرول‌بار اضافی نمایش داده نشود.

کنترل مستقل محورها

ویژگی‌های overflow-x و overflow-y امکان کنترل جداگانه‌ی سرریز در هر محور را فراهم می‌کنند. مثلاً می‌توانید محتوای عمودی قابل اسکرول باشد اما محتوای افقی مخفی شود.

style.css
.chat-window {
    width: 320px;
    height: 400px;
    overflow-x: hidden;
    overflow-y: auto;
    background-color: #f5f5f5;
}

در این مثال، پنجره‌ی چت در محور افقی هیچ اسکرول‌باری ندارد و محتوای اضافی مخفی می‌شود. اما در محور عمودی، وقتی پیام‌ها بیشتر شوند، اسکرول‌بار ظاهر می‌شود. این ترکیب برای طراحی چت‌باکس‌ها و لیست‌های پیام بسیار ایده‌آل است.
