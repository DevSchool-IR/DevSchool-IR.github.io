2D و 3D Transforms در CSS

ویژگی transform به شما اجازه می‌دهد یک عنصر را بدون آنکه روی چیدمان دیگر عناصر اثر بگذارد، جابه‌جا کنید، بچرخانید، تغییر اندازه دهید یا کج کنید. این افکت‌ها پایه‌ی بسیاری از تعاملات مدرن وب هستند.

جابه‌جایی با translate

translate(x, y) عنصر را از جای قبلی خود جابه‌جا می‌کند. در حالی که با margin بقیه‌ی المان‌ها هم جابه‌جا می‌شوند، ترنسفورم فقط خود عنصر را حرکت می‌دهد و بقیه‌ی صفحه به‌جای خود می‌مانند — برای مرکز کردن دقیق یک مودال یا انیمیشن، ایده‌آل است.

style.css
.overlay-card {
    transform: translate(-50%, -50%);
}

استفاده از درصد، جابه‌جایی را نسبت به اندازه‌ی خود عنصر محاسبه می‌کند. ترکیب آن با position: fixed یا absolute به‌طور کامل مرکز برای یک کادر متغیر می‌سازد.

چرخش با rotate

rotate(deg) عنصر را حول مرکز خودش می‌چرخاند؛ مقدار مثبت در جهت عقربه‌های ساعت و مقدار منفی خلاف جهت آن است.

style.css
.badge {
    transform: rotate(-6deg);
}
نکته: اگر می‌خواهید انیمیشن «چرخش مداوم» بسازید، سراغ transition فکر نکنید — از تابع rotate() با keyframes استفاده کنید تا حلقه کامل شود. این موضوع در فصل ۳۴ (Animations) کامل می‌شود.

تغییر اندازه با scale

scale(x, y) عرض و ارتفاع را بزرگ یا کوچک می‌کند. مقدار 1 یعنی اندازه‌ی اصلی؛ 0.5 نصف می‌کند و 2 دوبرابر. افزایش با hover افکت «بزرگ‌شدن» را می‌سازد.

style.css
.thumb:hover {
    transform: scale(1.1);
}

برخلاف تغییر width و height، مقیاس کردن عنصر را از مرکز رشد می‌دهد و چیزی به چیدمان اضافه نمی‌کند؛ بنابراین هیچ پرشی در صفحه رخ نمی‌دهد.

کج کردن با skew

skewX(deg) و skewY(deg) عنصر را در راستای افقی یا عمودی کش می‌دهند و ظاهری متمایل ایجاد می‌کنند — پرکاربرد در ساخت برچسب‌های مورب و دکمه‌های پویا.

style.css
.ribbon {
    transform: skewX(-12deg);
}

ترکیب چند تابع در یک transform مجاز است؛ ترتیب اهمیت دارد و از راست به چپ خوانده می‌شود. مثلاً transform: translate(10px) rotate(5deg) اولین بار جابه‌جا و بعد می‌چرخد.

مبدا تغییرات (transform-origin)

به‌صورت پیش‌فرض همه‌ی تغییرات حول مرکز عنصر انجام می‌شود. با transform-origin می‌توانید نقطه‌ی چرخش یا مقیاس را عوض کنید؛ مثلاً چرخش از لبه‌ی چپ یا بالای عنصر.

style.css
.flap {
    transform-origin: left top;
    transform: rotate(15deg);
}

این تنظیم برای افکت‌های «درِ باز شونده» و «باز شدن بال» بسیار پرکاربرد است؛ چرخش از لبه‌ای که انتخاب کرده‌اید اتفاق می‌افتد نه از مرکز.

دنیای 3D و perspective

برای عمق سه‌بعدی، دو چیز لازم است: ویژگی perspective روی والد برای تعریف فاصله‌ی چشم، و توابع سه‌بعدی مثل rotateX()، rotateY() و translateZ() روی فرزند.

style.css
.scene {
    perspective: 600px;
}

.card-3d {
    transform: rotateY(45deg);
}
هشدار: بدون perspective، توابع سه‌بعدی چیزی جز یک فشرده‌سازی مسطح نشان نمی‌دهند. هرچه عدد perspective کوچک‌تر باشد، عمق و انحراف از چشم بیشتر دیده می‌شود. پس از اعمال transform، محتوای متن هم ممکن است بریده شود؛ اگر لبه‌ها پرشدند، overflow: visible را بررسی کنید.
