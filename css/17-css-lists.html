استایل‌دهی لیست‌ها در CSS

در HTML دو نوع اصلی لیست وجود دارد: لیست نامرتب (Unordered List) با تگ <ul> که با نشانه نمایش داده می‌شود، و لیست مرتب (Ordered List) با تگ <ol> که با شماره نمایش داده می‌شود. با CSS می‌توان ظاهر این نشانه‌ها و همچنین فاصله‌ی موارد لیست را کنترل کرد.

نوع نشانه‌ی لیست (list-style-type)

ویژگی list-style-type نوع نشانه‌ی کنار هر مورد لیست را مشخص می‌کند. برخی از مقادیر رایج آن عبارت‌اند از:

  • disc: دایره‌ی توپر (مقدار پیش‌فرض برای لیست نامرتب)
  • circle: دایره‌ی توخالی
  • square: مربع توپر
  • decimal: شماره‌گذاری با اعداد (مقدار پیش‌فرض برای لیست مرتب)
  • none: بدون نشانه

style.css
ul {
    list-style-type: square; 
}

در این مثال، نشانه‌ی موارد لیست نامرتب از دایره‌ی پیش‌فرض به مربع توپر تغییر کرده است.

حذف نشانه‌ی لیست

یکی از کاربردهای رایج، حذف کامل نشانه‌های پیش‌فرض لیست است، که معمولاً برای ساخت منوهای ناوبری استفاده می‌شود.

style.css
ul {
    list-style-type: none; 
}

در این مثال، هیچ نشانه‌ای کنار موارد لیست نمایش داده نمی‌شود.

نکته: بعد از حذف نشانه‌ی لیست با list-style-type: none;، معمولاً باید مقدار padding-left عنصر ul یا ol نیز صفر شود، زیرا فضای خالی پیش‌فرض کنار لیست همچنان باقی می‌ماند.

موقعیت نشانه‌ی لیست (list-style-position)

ویژگی list-style-position مشخص می‌کند که نشانه‌ی لیست نسبت به متن، داخل یا خارج از جریان محتوا قرار بگیرد. مقادیر آن outside (پیش‌فرض) و inside هستند.

style.css
ul {
    list-style-position: inside;
}

در این مثال، نشانه‌ی لیست داخل محدوده‌ی متن قرار می‌گیرد و در صورت چندخطی شدن متن، خط دوم زیر نشانه قرار می‌گیرد نه زیر متن.

استایل کامل یک لیست ناوبری

با ترکیب چند ویژگی مختلف، می‌توان یک لیست ساده‌ی HTML را به یک منوی افقی تبدیل کرد.

style.css
ul {
    list-style-type: none;
    margin: 0;
    padding: 0;
}


li {
    display: inline-block;
    margin-right: 15px;
}

در این مثال، ابتدا نشانه‌ها و فاصله‌های پیش‌فرض لیست حذف شده‌اند، سپس با تنظیم display: inline-block; روی عنصر li، موارد لیست به‌جای نمایش زیر هم، به‌صورت افقی و کنار هم قرار می‌گیرند.
