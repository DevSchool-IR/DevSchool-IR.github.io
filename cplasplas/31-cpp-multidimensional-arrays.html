Multidimensional Arrays

آرایه‌ی چندبعدی مثل یک جدول است که داده‌ها را در سطر و ستون نگه می‌دارد؛ رایج‌ترین آن آرایه‌ی دو بعدی است.

تعریف آرایه‌ی دو بعدی

matrix.cpp
#include <iostream>

using namespace std;

int main() {
    int grid[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };

    cout << grid[1][2] << endl;

    return 0;
}
output
6

عدد 6 در سطر 1 و ستون 2 است؛ یعنی grid[1][2].

پیمایش با حلقه‌ی تودرتو

iterate.cpp
for (int row = 0; row < 2; row++) {
    for (int col = 0; col < 3; col++) {
        cout << grid[row][col] << " ";
    }
    cout << endl;
}
output
1 2 3
4 5 6

کاربردها

  • جدول‌های امتیاز و ماتریس‌های ریاضی.
  • صفحه‌ی بازی‌های تخته‌ای مثل شطرنج و ماروپله.
  • تصاویر که پیکسل‌های سطر و ستونی هستند.
نکته: برای آرایه‌های چندبعدی پویا و مرتب‌سازی ساده، معمولاً vector یا کتابخانه‌های عددی مناسب‌ترند که در فصل‌های STL می‌بینید.

در فصل بعد رشته‌های C++ یعنی std::string را بررسی می‌کنیم.
