CSS Variables

Bootstrap 5 به‌جای Sass Variables برای بسیاری از بخش‌ها از CSS Variables استفاده می‌کند. این متغیرها با پیشوند --bs- روی :root تعریف شده‌اند و به شما اجازه می‌دهند بدون کامپایل، رنگ‌ها و استایل‌ها را در زمان اجرا سفارشی کنید.

متغیرهای ریشه (Root Variables)

با مراجعه به EleMS.com یا باز کردن bootstrap.css می‌توانید متغیرهایی مانند --bs-primary، --bs-body-bg و --bs-border-radius را روی :root ببینید. این متغیرها پایه استایل کل پروژه هستند.

example-css-variables.html
<style>

:root --my-accent: #ff6600;

</style>

<div class="text-primary bg-light p-3 border rounded">

    متن با رنگ متغیر bootstrap

</div>
نکته: کلاس‌های Utilities مانند bg-*، text-*، border-* و shadow-* در Bootstrap 5 از متغیرهای CSS استفاده می‌کنند؛ بنابراین با تغییر متغیر، تمام کلاس‌های مربوطه هم‌زمان تغییر می‌کنند.

سفارشی‌سازی با متغیرهای CSS

ساده‌ترین راه تغییر تم، بازتعریف متغیرها روی :root است. به این ترتیب تمام کامپوننت‌ها به‌صورت خودکار رنگ جدید را می‌گیرند؛ حتی بدون نیاز به Sass.

  • --bs-primary: رنگ اصلی
  • --bs-secondary: رنگ ثانویه
  • --bs-body-bg: پس‌زمینه صفحه
  • --bs-body-color: رنگ متن اصلی
  • --bs-border-radius: گردی گوشه‌ها
  • --bs-font-sans-serif: فونت خانواده
example-override-variables.html
<style>

:root {

    --bs-primary: #6f42c1;

    --bs-primary-rgb: 111, 66, 193;

    --bs-body-bg: #f7f3ff;

}

</style>
نکته: برای متغیرهای رنگ که برای bg-opacity و text-opacity استفاده می‌شوند، حتماً نسخه RGB را هم تعریف کنید، مانند --bs-primary-rgb.

متغیرهای حداقل و حداکثر در کامپوننت‌ها

برخی متغیرها به‌صورت محلی روی کامپوننت‌ها تعریف شده‌اند، مثل --bs-body-bg یا --bs-border-color. برای تغییر یک کامپوننت خاص، می‌توانید متغیر را روی همان انتخابگر بازتعریف کنید.

example-component-variables.html
<style>

.card-custom {

    --bs-card-border-color: #ff6600;

    --bs-card-border-width: 2px;

    --bs-card-border-radius: 1.5rem;

    --bs-card-bg: #fff8f0;

}

</style>

مزایا و کاربردها

با متغیرهای CSS می‌توانید تم‌های پویا بسازید؛ مثلاً با تغییر یک متغیر در JavaScript، حالت تاریک/روشن را پیاده کنید. همچنین برای پشتیبانی از Theme به روزرسانی زمان اجرا مناسب‌تر از Sass هستند.

  • تم‌سازی پویا در زمان اجرا بدون ری‌کامپایل
  • کاهش کد تکراری با var()
  • امکان ساخت Dark/Light به سادگی با تغییر چند متغیر
  • هماهنگی با کامپوننت‌های مبتنی بر Utility
