Utility API

Utility API در Bootstrap 5 یک مکانیزم Sass است که به شما اجازه می‌دهد کلاس‌های کمکی (Utilities) را بسازید، تغییر دهید یا حذف کنید. تمام Utilities پیش‌فرض Bootstrap از طریق این API و یک Saf Map به نام $utilities تولید می‌شوند.

ساختار یک Utility در API

هر Utility یک آیتم در $utilities map است که با کلاس‌هایی مانند property، values، class و responsive تعریف می‌شود.

scss/_custom-utility.scss
@import "bootstrap/scss/functions";

@import "bootstrap/scss/variables";

@import "bootstrap/scss/utilities";



$utilities: map-merge($utilities, (

    "cursor": (

        property: cursor,

        class: cursor,

        values: auto pointer grab not-allowed

    )

));
نکته: کلیدهای هر آیتم در Utility API عبارت‌اند از property (ویژگی CSS)، values (مقادیر)، class (پیشوند کلاس)، responsive (ساخت نسخه برای Breakpointها) و print (ساخت برای مد چاپ).

کلیدهای مهم Utility API

برای کنترل دقیق خروجی، می‌توانید از کلیدهای بیشتری استفاده کنید.

  • property: نام ویژگی CSS مثل background-color
  • values: لیست مقادیر یا map نام به مقدار
  • class: پیشوند نام کلاس
  • responsive: ساخت کلاس‌های -sm تا -xxl
  • state: تولید کلاس با پیشوند :hover و :focus
  • print: تولید کلاس داخل media چاپ
  • css-var: خروجی به صورت CSS Variable
  • local-vars: تعریف متغیرهای محلی
  • rtl: تولید یا حذف نسخه RTL

حذف یا ویرایش Utilities پیش‌فرض

برای حذف یک Utility از map.remove() و برای تغییر مقادیر از map-merge() استفاده کنید. به عنوان نمونه، اگر نمی‌خواهید کلاس‌های رنگی text-* تولید شوند، کافیست آن‌ها را از $utilities حذف کنید.

scss/_edit-utilities.scss
$utilities: map-remove($utilities, "text-danger");



$utilities: map-merge($utilities, (

    "opacity": (

        property: opacity,

        values: (

            0: 0,

            10: 0.1,

            20: 0.2,

            100: 1

        )

    )

));
نکته: برای استفاده از Utility API باید Bootstrap را با Sass کامپایل کنید. با نسخه فشرده CSS آماده (bootstrap.min.css) امکان ویرایش Utilities وجود ندارد.

نکات جمع‌بندی

هر بار فقط Utilities موردنیاز خود را وارد کنید تا حجم CSS نهایی کمتر شود؛ مثلاً از import "bootstrap/scss/utilities/api" استفاده کنید.

  • Utility API جایگزین ضرورت بخش‌های جداگانه مانند margin.scss شده است.
  • با map-merge می‌توانید کلاس‌های سفارشی اضافه کنید.
  • با map-remove می‌توانید کلاس‌های اضافی را حذف کنید.
  • از css-var برای خروجی‌هایی که از CSS Variable استفاده می‌کنند بهره ببرید.
