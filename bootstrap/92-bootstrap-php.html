PHP

PHP یکی از قدیمی‌ترین و پرکاربردترین زبان‌های Backend وب است. با استفاده از توابع Include PHP می‌توانید قالب‌های مشترک Bootstrap بسازید و از تکرار کد جلوگیری کنید.

ساختار پوشه و فایل‌های مشترک

بهترین روش استفاده از PHP این است که فایل‌های Header و Footer را جداگانه بسازید و با include در هر صفحه فراخوانی کنید.

includes/header.php
<!DOCTYPE html>

<html lang="fa" dir="rtl">

<head>

    <meta charset="UTF-8">

    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

    <title><?php echo $page_title; ?></title>

</head>

<body>

صفحه اصلی با Include

فایل‌های header و footer را در هر صفحه فراخوانی کنید و محتوای اختصاصی هر صفحه را بین آنها قرار دهید.

index.php
<?php

$page_title = "خانه";

include 'includes/header.php';

?>



<div class="container mt-4">

    <div class="row">

        <?php

        $products = [

            ["name" => "محصول ۱", "price" => "۱۰۰,۰۰۰ تومان"],

            ["name" => "محصول ۲", "price" => "۲۰۰,۰۰۰ تومان"],

        ];

        foreach ($products as $p) :

        ?>

        <div class="col-md-4">

            <div class="card mb-3">

                <div class="card-body">

                    <h5 class="card-title"><?php echo $p["name"]; ?></h5>

                    <p class="card-text"><?php echo $p["price"]; ?></p>

                </div>

            </div>

        </div>

        <?php endforeach; ?>

    </div>

</div>



<?php include 'includes/footer.php'; ?>
نکته: متغیر $page_title قبل از include تعریف می‌شود تا عنوان صفحه در Header به درستی نمایش داده شود. این روش الگوی Variable Passing در PHP است.

فرم‌های Bootstrap در PHP

پردازش فرم‌ها در PHP با استفاده از متغیر $_POST و ترکیب با کلاس‌های فرم Bootstrap بسیار ساده است.

contact.php
<?php

$success = false;

if ($_SERVER["REQUEST_METHOD"] === "POST") {

    $name = htmlspecialchars($_POST["name"]);

    $email = htmlspecialchars($_POST["email"]);

    $message = htmlspecialchars($_POST["message"]);

    $success = true;

}

include 'includes/header.php';

?>



<div class="container mt-4">

    <?php if ($success): ?>

    <div class="alert alert-success">پیام شما ارسال شد!</div>

    <?php endif; ?>

    <form method="POST">

        <div class="mb-3">

            <input type="text" name="name" class="form-control" placeholder="نام" required>

        </div>

        <div class="mb-3">

            <input type="email" name="email" class="form-control" placeholder="ایمیل" required>

        </div>

        <div class="mb-3">

            <textarea name="message" class="form-control" rows="4"></textarea>

        </div>

        <button type="submit" class="btn btn-primary">ارسال</button>

    </form>

</div>
  • فایل‌های تکراری (Header, Footer, Navbar) را در پوشه includes/ قرار دهید
  • از include یا require برای فراخوانی فایل‌های مشترک استفاده کنید
  • متغیرهایی که قبل از include تعریف می‌شوند، در فایل Include در دسترس هستند
  • برای امنیت، همیشه ورودی‌ها را با htmlspecialchars() فیلتر کنید
نکته: در پروژه‌های PHP بزرگتر، استفاده از Composer و فریم‌ورکهایی مانند Laravel یا Symfony با Bootstrap بهترین نتیجه را می‌دهد.
