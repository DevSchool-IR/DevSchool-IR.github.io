Structs

Struct شبیه به کلاس است، ولی یک نوع مقداری (value type) است. برای داده‌های کوچک و سبک مناسب است.

تعریف

Point.cs
struct Point
{
    public int X;
    public int Y;
}

استفاده

Program.cs
Point p = new Point();
p.X = 10;
p.Y = 20;

Console.WriteLine(p.X));  // 10

کپی مستقل (برخلاف کلاس)

Program.cs
Point p1 = new Point();
p1.X = 5;

Point p2 = p1;
p2.X = 100;

Console.WriteLine(p1.X));  // 5 (کپی مستقل)
Console.WriteLine(p2.X));  // 100

struct با سازنده

Rectangle.cs
struct Rectangle
{
    public double Width;
    public double Height;

    public Rectangle(double width, double height)
    {
        Width = width;
        Height = height;
    }

    public double Area()
    {
        return Width * Height;
    }
}
نکته: کلاس «نوع مرجعی» است و کپی‌ها به همان آبجکت اشاره می‌کنند؛ struct به‌صورت کپی مقدار رفتار می‌کند.
