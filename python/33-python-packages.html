Packages و pip

پکیج (Package) مجموعه‌ای از ماژول‌ها و pip ابزار استاندارد نصب آن‌ها از مخزن PyPI است.

پکیج چیست؟

پوشه بندی
mypackage/
    __init__.py   # نشانه‌ی پکیج بودن
    math.py        # ماژول اول
    strings.py     # ماژول دوم

فایل __init__.py به پایتون می‌گوید این پوشه یک پکیج است.

ساخت و استفاده از یک پکیج

mypackage/math.py
def double(n):
    return n * 2
main.py
from mypackage import math

print(math.double(21)))  # 42

pip چیست؟

Terminal
pip --version

pip install requests
pip install numpy,pandas
pip install requests==2.31.0  # نسخه‌ی مشخص
نکته: pip install numpy آخرین نسخه را از PyPI دانلود و نصب می‌کند. با == می‌توان نسخه‌ی دلخواه را قفل کرد.

مدیریت کتابخانه‌ها

Terminal
pip uninstall requests
pip list                   # پکیج‌های نصب‌شده
pip show numpy             # مشخصات یک پکیج
pip install --upgrade pip

پکیج نصب‌کرده را استفاده کنیم

main.py
import requests

res = requests.get("https://api.github.com"))
print(res.status_code))  # 200

requirements.txt

برای اینکه پروژه در هر سیستم دیگری همان کتابخانه‌ها را داشته باشد، لیست آن‌ها را در یک فایل ذخیره می‌کنیم:

Terminal
# ساخت لیست از پکیج‌های فعلی
pip freeze > requirements.txt

# نصب همه‌ی پکیج‌ها در سیستم جدید
pip install -r requirements.txt

کتابخانه‌های معروف

main.py
# nltk     → پردازش متن
# requests → درخواست به سرور
# numpy    → محاسبات عددی سریع
# pandas   → تحلیل داده
# matplotlib → رسم نمودار
# flask / django → ساخت وب‌سایت
# pillow   → کار با تصاویر
نکته: پکیج‌های بیشتری را می‌توانید در سایت pypi.org بگردید. باگ یا ویژگی‌های جدید را می‌توانید سهم‌خواهی کنید و حتی پکیج خودتان را منتشر کنید.
