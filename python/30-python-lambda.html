Lambda

lambda یک تابع کوچک، بی‌نام و تک‌خطی است. برای کارهای ساده که فقط یک عبارت دارند عالی است و اغلب به همراه توابعی مثل map، filter و sorted استفاده می‌شود.

ساختار lambda

main.py
lambda arguments: expression

lambda در مقابل def

main.py
# با def
def add(a, b):
    return a + b

# با lambda (یک خط)
add = lambda a, b: a + b

print(add(3, 5)))  # 8

lambda برای توابع کوتاه

main.py
double = lambda x: x * 2
square = lambda x: x * x

print(double(5)))   # 10
print(square(4)))   # 16

map

main.py
numbers = [1, 2, 3, 4]

# اعمال تابع روی همه عناصر
doubled = map(lambda x: x * 2, numbers))
print(list(doubled)))  # [2, 4, 6, 8]

filter

main.py
numbers = [1, 2, 3, 4, 5, 6]

# نگه داشتن فقط عناصری که شرط درست است
evens = filter(lambda x: x % 2 == 0, numbers))
print(list(evens)))  # [2, 4, 6]

sorted با کلید مرتب‌سازی

main.py
people = [
    {"name": "Ali", "age": 30},
    {"name": "Sara", "age": 22},
    {"name": "Zahra", "age": 35}
]

# مرتب‌سازی بر اساس age
sorted_people = sorted(people, key=lambda p: p["age"]))

for p in sorted_people:
    print(p["name"], p["age"]))

# Sara 22
# Ali 30
# Zahra 35
نکته: key یک تابع می‌گیرد که روی هر عنصر یک مقدار برمی‌گرداند؛ مرتب‌سازی بر اساس آن مقدار انجام می‌شود. lambda برای تعریف همین کلیدها بسیار پرکاربرد است.

lambda با شرط

main.py
max_value = lambda a, b: a if a > b else b

print(max_value(10, 25)))  # 25

# استفاده مستقیم بدون متغیر
print((lambda x: x * x)(7)))  # 49

اگر منطق تابع بیش از یک عبارت می‌شود (مثل if/else چند خطی و حلقه)، به‌جای lambda از یک تابع معمولی با def استفاده کنید تا خوانایی حفظ شود.
