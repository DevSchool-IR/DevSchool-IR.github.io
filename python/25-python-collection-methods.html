فصل ۲۵ | Python Collections

Collection Methods

در این فصل با متدها و توابع کاربردی‌ای آشنا می‌شویم که کار با مجموعه‌ها (لیست، تاپل، set و دیکشنری) را خیلی ساده‌تر می‌کنند.

min و max

main.py
nums = [3, 7, 1, 9]

print(min(nums))  # 1
print(max(nums))  # 9
print(sum(nums))  # 20

len، sorted و reversed

main.py
words = ["apple", "kiwi", "banana"]

print(len(words))         # 3
print(sorted(words)))     # ['apple', 'banana', 'kiwi']

rev = list(reversed(words)))
print(rev)  # ['banana', 'kiwi', 'apple']

enumerate

main.py
colors = ["red", "green", "blue"]

for i, color in enumerate(colors):
    print(i, color))

# 0 red
# 1 green
# 2 blue

# با شمارنده متفاوت
for i, color in enumerate(colors, start=1):
    print(i, color))

zip

main.py
names = ["Ali", "Sara", "Omid"]
ages = [25, 22, 30]

for name, age in zip(names, ages):
    print(name, age))

# Ali 25
# Sara 22
# Omid 30

pairs = list(zip(names, ages)))
print(pairs)  # [('Ali', 25), ('Sara', 22), ('Omid', 30)]

join و split

main.py
items = ["html", "css", "python"]

# join — چسباندن اعضای لیست به هم
text = ", ".join(items)
print(text)  # html, css, python

# split — بریدن رشته به لیست
nums_str = "1,2,3,4"
nums = nums_str.split(",")
print(nums)  # ['1', '2', '3', '4']
نکته: join روی رشته‌ی جداکننده صدا زده می‌شود و لیست را به عنوان آرگومان می‌گیرد. split هم برعکس، روی رشته صدا زده می‌شود.

any و all

main.py
bools = [True, False, True]

print(any(bools))  # True — حداقل یکی True
print(all(bools))  # False — همه باید True باشند

# کاربرد با شرط
nums = [2, 4, 6]
print(all(n % 2 == 0 for n in nums)))  # True

تابع نمونه: آمار یک لیست

main.py
def stats(data):
    return {
        "min": min(data),
        "max": max(data),
        "sum": sum(data),
        "len": len(data)
    }

result = stats([4, 9, 2])
print(result))
