با چه ابزاری HTML بنویسیم؟

برای نوشتن HTML به هیچ نرم‌افزار خاص یا گران‌قیمتی نیاز ندارید. یک ویرایشگر متن ساده کافی است؛ چون فایل‌های HTML در واقع فایل‌های متنی معمولی هستند که فقط پسوند .html دارند. با این حال، استفاده از یک ویرایشگر کد مناسب کار شما را بسیار سریع‌تر و بدون خطا می‌کند.

محبوب‌ترین ابزار در بین توسعه‌دهندگان امروزی، ویرایشگر Visual Studio Code است که رایگان، سبک و دارای امکاناتی مثل تکمیل خودکار کد، هایلایت رنگی و پیش‌نمایش زنده است. گزینه‌های دیگری مثل Sublime Text، WebStorm یا حتی Notepad ساده‌ی ویندوز هم برای این کار قابل استفاده‌اند.

نکته: هرگز از نرم‌افزارهای واژه‌پرداز مثل Word برای نوشتن HTML استفاده نکنید؛ این برنامه‌ها کدهای اضافی و پنهانی به فایل اضافه می‌کنند که باعث به‌هم‌ریختن صفحه می‌شود.

مراحل ساخت اولین فایل

  1. ویرایشگر متن را باز کنید.
  2. کد HTML را بنویسید یا کپی کنید.
  3. فایل را با نامی مثل index.html ذخیره کنید.
  4. فایل ذخیره‌شده را با دابل‌کلیک در مرورگر باز کنید تا نتیجه را ببینید.
index.html
<!DOCTYPE html>
<html>
<body>

    <h1>عنوان صفحه من</h1>
    <p>این فایل با یک ویرایشگر ساده ساخته شده.</p>

</body>
</html>

پس از ذخیره‌ی فایل، کافی است آیکن آن را در پوشه پیدا کرده و روی آن دوبار کلیک کنید؛ مرورگر پیش‌فرض سیستم شما به‌طور خودکار آن را باز و اجرا می‌کند. هر بار که کد را تغییر می‌دهید، فقط کافی است فایل را دوباره ذخیره کرده و صفحه‌ی مرورگر را رفرش کنید.
