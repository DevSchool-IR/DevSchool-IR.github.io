Browser و BOM

BOM یعنی «مدلِ آبجکتیِ مرورگر»؛ آن بخشی از JavaScript که به خودِ مرورگر دسترسی دارد: پنجره، آدرس، تاریخچه و اطلاعاتِ مرورگر. برخلاف DOM که به صفحه کار دارد، BOM به محیطِ مرورگر است.

window

window بالاترین آبجکتِ مرورگر است؛ همه‌ی متغیرهای سراسری و بیشترِ این‌ها عضوِ آن‌اند. حتی document هم زیرِ پنجره است:

index.html
console.log(window.innerWidth);    // عرض صفحه
console.log(window.innerHeight);   // ارتفاع صفحه
console.log(window.location.href);   // آدرس کامل

location

آدرس فعلی و رفتن به صفحه‌ی دیگر با location انجام می‌شود:

index.html
console.log(location.hostname);      // devschool-ir.github.io
console.log(location.pathname);     // /javascript/39-...

// redirect بعد از چند ثانیه
setTimeout(function() {
    location.href = "https://devschool-ir.github.io";
}, 3000);

history

تاریخچه‌ی بازدیدِ تبِ فعلی با history مدیریت می‌شود:

index.html
history.back();          // یک قدم به عقب
history.forward();       // یک قدم جلو
history.go(-1);         // همان back
console.log(history.length);

navigator

اطلاعاتِ مرورگر و دستگاه کاربر: نام مرورگر، زبان، آنلاین بودن و موارد دیگر:

index.html
console.log(navigator.userAgent);      // شناسه‌ی مرورگر
console.log(navigator.language);      // زبان سیستم
console.log(navigator.onLine);       // online یا offline

جعبه‌های گفت‌وگو

index.html
alert("هشدار! فرم ناقص است!");

let check = confirm("ادامه بدهیم؟");
console.log(check);   // true یا false

let name = prompt("نام شما؟");
نکته: alert و confirm و prompt ساده‌اند ولی «بلاک‌کننده» هم هستند و در گوشی تجربه‌ی بدی می‌دهند؛ در پروژه‌های واقعی از مودالِ سفارشی استفاده کنید.

تایمرها

index.html
let timer = setTimeout(function() {
    console.log("۳ ثانیه گذشت");
}, 3000);

// لغو قبل از اجرا
clearTimeout(timer);

let clicks = 0;
let counter = setInterval(function() {
    clicks++;
    console.log(clicks);
}, 1000);

setTimeout(function() {
    clearInterval(counter);   // متوقف کردن بعد از ۱۰ ثانیه
}, 10000);

setTimeout یک‌بار بعد از تأخیر اجرا می‌شود و setInterval هر چند ثانیه تکرار می‌شود. برای هر دو باید id را نگه دارید تا بتوانید با clear متوقفشان کنید.

چرا BOM مهم است؟

  • هدایت کاربر به صفحه‌ی دیگر (لاگین، امنیت)
  • تشخیص مرورگر و زبان برای رندرِ متناسب
  • شمارنده‌های زمان و اسلایدرهای خودکار
  • تشخیص وضعیت آنلاین/آفلاین

با این‌ها بخشِ «محیطِ اجرا» کامل شد. در فصل بعد واردِ ذخیره‌سازیِ ماندگار در مرورگر می‌شویم؛ جایی که داده‌ی کاربر تا دفعه‌ی بعد زنده می‌ماند.
