if و else

تا اینجا برنامه‌ها خط‌به‌خط اجرا می‌شدند؛ با if کنترل جریان واقعاً شروع می‌شود. حالا برنامه می‌تواند بر اساس یک شرط تصمیم بگیرد.

ساختار پایه

index.html
<script>
    let age = 17;

    if (age >= 18) {
        console.log("مجاز به ورود");
    }
    else {
        console.log("هنوز نوجوانید");
    }
</script>

اگر شرطِ داخل پرانتز true باشد، بلوک اول اجرا می‌شود؛ در غیر این صورت بلوک else. در این مثال چون ۱۷ از ۱۸ کوچک‌تر است، پیام دوم چاپ می‌شود.

else if — چند شاخه

برای بیش از دو حالت، شاخه‌های else if را پشت سر هم می‌چینیم؛ اولی که درست باشد اجرا شده و باقی نادیده گرفته می‌شوند:

index.html
<script>
    let score = 75;

    if (score >= 90) {
        console.log("عالی");
    } else if (score >= 70) {
        console.log("خوب");
    } else {
        console.log("سعی کنید");
    }
</script>

نمره‌ی ۷۵ نه از ۹۰ بزرگ‌تر است و نه الزاماً از ۷۰؛ پس شاخه‌ی «خوب» اجرا می‌شود. ترتیب شرط‌ها مهم است؛ از «محدودترین» به سمت «کلی‌ترین» بنویسید.

نکته: هر مقداری به boolean تبدیل می‌شود. عددِ صفر، رشته‌ی خالی، null و undefined «فالسی» محسوب می‌شوند و بقیه «تروثی»؛ یعنی امتحان کنید با if (name) نه با if (name === true).

عملگر سه‌تایی (Ternary)

برای حالت ساده‌ی «یا این یا اون»، عملگر سه‌تایی کوتاه‌تر است؛ شکلش «شرط ؟ جواب درست : جواب غلط» است:

index.html
<script>
    let ticket = 25;
    let price = ticket >= 18 ? "بزرگسال" : "کودک";

    console.log(price);  // بزرگسال
</script>

نگه‌داشتنِ نتیجه‌ی یک شرط ساده در متغیر، کد را تمیزتر می‌کند؛ اگر شرط پیچیده بود یا بلوک‌ها طولانی، سراغ if/else برگردید.
