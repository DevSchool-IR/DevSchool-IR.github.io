DOM

DOM یا «مدلِ آبجکتیِ سند» نمایِ برنامه‌پذیرِ صفحه است. مرورگر HTML را به یک درختِ آبجکت تبدیل می‌کند و JavaScript با همین درخت، عناصر را پیدا، تغییر و جابه‌جا می‌کند.

پیدا کردن عنصر

document نقطه‌ی ورودِ همه‌چیز است. با querySelector یک عنصر و با querySelectorAll همه‌ی تطبیق‌ها را می‌گیریم:

index.html
let title = document.querySelector("#title");          // با id
let buttons = document.querySelectorAll(".btn");   // با کلاس
let first = document.querySelector(".btn");     // اولین

console.log(buttons.length);   // تعداد دکمه‌ها

سینتکسِ querySelector همان انتخابگرهای CSS است: #id و .class و selector. اگر عنصری پیدا نشود، null برمی‌گردد.

هشدار: اگر از null.querySelector استفاده کنید خطا می‌گیرید. همیشه اول بررسی کنید مقدارِ بازگشتی null نیست یا از ?. استفاده کنید.

تغییر محتوا

index.html
let title = document.querySelector("#title");

title.textContent = "سلام از JavaScript";
title.innerHTML = "<b>سلام</b> از JavaScript";
تفاوت: textContent متن خام می‌گذارد و HTML نیست؛ innerHTML تگ‌های داخلِ رشته را «اجرا» می‌کند. با داده‌ی کاربر از innerHTML استفاده نکنید؛ خطرِ XSS دارد.

استایل و کلاس

index.html
let box = document.querySelector(".box");

box.style.color = "red";
box.style.backgroundColor = "#eee";

box.classList.add("active");
box.classList.remove("old");
box.classList.toggle("hidden");

ساخت و افزودن عنصر

index.html
let list = document.querySelector("ul");

let item = document.createElement("li");
item.textContent = "عضو جدید";

list.appendChild(item);

let extra = document.createElement("li");
extra.textContent = "عضو دیگر";
list.insertBefore(extra, list.firstChild);

حذف عنصر

index.html
let msg = document.querySelector("#message");

msg.remove();   // حذف از صفحه

document.body.textContent = "";   // پاک کردن همه (خطرناک)

کجا ازش استفاده کنیم؟

  • به‌روزرسانی متن و عنوان صفحه بدون رفرش
  • نمایش/پنهان کردن منو و مودال
  • رندرِ لیست داده‌ها از روی آرایه
  • اعتبارسنجی و نمایش خطای فرم‌ها

DOM قلبِ تعامل صفحه است؛ هر جا می‌بینید بدون رفرش چیزی عوض می‌شود، پشت صحنه همین انتخاب‌ها و تغییرات است. در فصل بعد می‌آموزیم چطور این تغییرات را به «رخدادِ کاربر» ببندیم.
