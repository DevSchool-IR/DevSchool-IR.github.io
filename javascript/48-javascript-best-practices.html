Best Practices

تبریک! شما به آخر دوره رسیدید. این فصل «دوره‌ی مرورِ نظم» است: عادت‌هایی که باعث می‌شود کدِ شما خوانا، قابل‌نگهداری و کم‌خطا باشد — حتی اگر پروژه بزرگ شود.

نام‌های معنادار

نام متغیر باید بگوید «چه چیزی را نگه می‌دارد». نه درست است که بنویسیم let x = 1000؛ چه باشد بهتر:

index.html
const MAX_SCORE = userScore > 90;   // بد: معنا ندارد
const isPassed = userScore > 90;   // خوب: یک جمله‌ی خوانا
علت نام‌گذاری: کد بیش از آن‌که نوشته شود، «خوانده» می‌شود — بعداً خودِ شما یا همکارتان. نامِ خوب، کامنتِ رایگان است.

const اول، var هرگز

متغیری که عوضش نمی‌کنیم const؛ فقط جاهایی که حتماً باید مقدارش تغییر کند let. var را کنار بگذارید؛ دامنه‌ی قدیمی و گیج‌کننده دارد.

index.html
const price = 100;            // مقدار ثابت
let count = 0;               // در حلقه عوض می‌شود
var oldValue = 5;        // var: نپرسید!

عدم تکرار: یک تابع برای هر کار

هر قطعه کدی که دوبار می‌نویسیم، باید یک تابع یا ابزار شود. اصلِ معروف: «DRY — Don't Repeat Yourself»:

index.html
function getDiscountedPrice(price, percent) {
    return price − price * percent / 100;
}

let summerPrice = getDiscountedPrice(150, 20);
let winterPrice = getDiscountedPrice(150, 35);

خطاگیری را جدی بگیرید

کدِ شبکه و ورودی کاربر همیشه ممکن است شکست بخورد؛ بنابراین همیشه try/catch درست بگذارید:

index.html
async function loadProfile() {
    try {
        let response = await fetch("/api/profile");
        if (!response.ok) {
            throw new Error("خطا در دریافت");
        }
        console.log(await response.json());
    } catch (error) {
        console.log("خطا: " + error.message);
    }
}

از عملگرها ساده استفاده کنید

قطعه‌های پیچیده را به خط‌های ساده بشکنید؛ کدِ کوتاه «بخاطر کوتاهی» هرگز هدف نیست — خوانایی هدف است:

index.html
let total = items.filter(item => item.price > 0)
    .map(item => item.price)
    .reduce((sum, price) => sum + price, 0);
نکته: زنجیره‌ی منطقیِ آرایه‌ها خواناست و به «جمله‌های جدا» تقسیم می‌شود. سعی کنید هر خط به آسانی با چشم مرور شود.

کامنت یعنی «چرا»

کد به خودش بگوید «چه می‌کند»؛ کامنت بگوید «چرا این کار را می‌کند». توضیحِ «چیستیِ» بدیهی فقط صدا را زیاد می‌کند.

index.html
// جمع امتیازها را می‌شماریم (بد: مشخص است)
let total = scores.reduce((a, b) => a + b, 0);

// امتیازهای خالی در API صفر نیستند، باید نادیده گرفته شوند
let total = scores
    .filter(score => score != null)
    .reduce((a, b) => a + b, 0);

چک‌لیست کد تمیز

  • نام‌های طولانی و معنادار بهتر از کوتاه و مبهم
  • const تا حد امکان و let فقط برای مقدارِ متغیر
  • هر تابع یک کار انجام دهد
  • کدِ تکراری → تابع یا ماژول
  • خطای شبکه و ورودی همواره با try/catch
  • کامنت برای «چرا»، نه برای «چه»
  • قبل از ارسال به سرور، ورودی کاربر را check کنید
  • بدون var و بدون مقایسه‌ی غیرسختگیرانه‌ی ناخواسته
