روش‌های اجرای JavaScript

کدهای JavaScript را می‌توان به سه شکل در یک صفحه وب قرار داد: داخل تگ <script> در بخش head، داخل body، یا در یک فایل خارجی با پسوند .js. انتخاب هر روش به نیاز پروژه بستگی دارد.

سینتکس تگ script

مرورگر از اتریبیوت src برای لود کردن فایل خارجی و از محتوای داخل تگ برای کدهای مستقیم استفاده می‌کند. یک تگ <script> می‌تواند فقط یکی از این دو کار را انجام دهد.

نکته: در HTML قدیمی از اتریبیوت type="text/javascript" استفاده می‌شد، اما در HTML5 این مقدار پیش‌فرض است و نیازی به نوشتن آن ندارید.

اسکریپت در بخش head

کد را داخل بخش head قرار می‌دهیم تا قبل از نمایش محتوا بارگذاری شود؛ مناسب توابعی است که سریع تعریف شوند:

index.html
<!DOCTYPE html>
<html>
<head>
    <script>
        function welcome() {
            confirm("به سایت ما خوش آمدید");
        }
    </script>
</head>
<body>
    <h1>قاب دوم دوره جاوااسکریپت</h1>
</body>
</html>

تابع welcome() فقط تعریف شده است و اجرا نمی‌شود؛ تا زمانی که آن را صدا نزنید کاری انجام نمی‌دهد.

اسکریپت در بخش body

هدف معمول، اجرای کد بعد از ساخته شدن عناصر صفحه است. در این مثال متن یک پاراگراف عوض می‌شود و پیام‌ها در کنسول نمایش داده می‌شود:

index.html
<body>
    <h1>امروز</h1>
    <p id="demo">یک پاراگراف نمونه</p>

    <script>
        document.write("تاریخ امروز");
        console.log("اسکریپت در body اجرا شد");
    </script>

</body>

تگ <script> را معمولاً در پایان بخش body قرار می‌دهیم تا اول محتوا لود شود و سپس اسکریپت اجرا گردد؛ این کار سرعت ادراک کاربر از صفحه را بهتر می‌کند.

فایل خارجی JavaScript

کد را در یک فایل جداگانه با پسوند .js بنویسید و با اتریبیوت src به صفحه متصل کنید:

index.html
<body>
    <button onclick="sayHello()">سلام</button>

    <script src="app.js"></script>
</body>
app.js
function sayHello() {
    alert("سلام از یک فایل خارجی!");
}

فایل خارجی فقط تگ مجاز script را باز و بسته نمی‌کند؛ کد را مستقیم و بدون تگ می‌نویسیم. این روش تمیزترین راه برای پروژه‌های واقعی است.

چرا فایل خارجی بهتر است؟

  • جداسازی HTML از JavaScript و خوانایی بیشتر کد
  • استفاده مجدد: یک فایل را می‌توان به چند صفحه وصل کرد
  • کش شدن توسط مرورگر و بارگذاری سریع‌تر در دفعات بعد
  • دِباگ ساده‌تر در ابزارهای توسعه‌دهنده

تگ <script> بدون اتریبیوت src کد درونی را اجرا می‌کند. اگر هم src باشد و هم کد درونی، مرورگر فقط فایل خارجی را اجرا می‌کند؛ پس این دو را با هم استفاده نکنید.

هشدار: اسکریپت‌ها را به ترتیب موردنیاز لود کنید؛ اگر فایلی به فایل دیگر وابسته است، فایل وابسته باید اول لود شود.
