Siblings

المان‌هایی که والد مشترک دارند همسایه هستند. با siblings همه‌شان، و با next و prev فقط بعدی و قبلی گرفته می‌شود.

همه‌ی همسایه‌ها

script.js
$("#demo").siblings().hide();

خود #demo می‌ماند و بقیه‌ی بچه‌های همان والد مخفی می‌شوند. خود المان هیچ‌وقت جزو همسایه‌های خودش نیست.

بعدی و قبلی

script.js
$("#demo").next().hide(); // همسایه‌ی بعدی
$("#demo").prev().hide(); // همسایه‌ی قبلی
متد محدوده
siblings() همه‌ی همسایه‌ها (به‌جز خودش)
next() / prev() فقط یکی بعدی / قبلی
nextAll() / prevAll() همه‌ی بعدی‌ها / قبلی‌ها
