Array Operators

PHP برای آرایه‌ها عملگر ویژه دارد؛ مهم‌ترین آن + است که دو آرایه را ادغام می‌کند.

اتحاد با +

index.php
<?php
$a = ["a" => "red"];
$b = ["b" => "blue"];
$c = $a + $b;  // هر دو کلید کنار هم
print_r($c);
?>
نکته: در اتحاد، اگر هر دو آرایه کلید یکسان داشته باشند، کلید سمت چپ نگهداری می‌شود و سمت راست نادیده گرفته می‌شود.

مقایسه‌ی آرایه‌ها

index.php
<?php
$x = [1, 2];
$y = [1, 2];
var_dump($x == $y);   // true
var_dump($x === $y);  // true
$z = [2, 1];
var_dump($x == $z);   // false؛ ترتیب مهم است
?>

برای فرق بین برابر بودن مقدار (==) و یکسان بودن مقدار و نوع (===) در آرایه هم مثل بقیه جاها دقت کنید.
