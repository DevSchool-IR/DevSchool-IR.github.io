UNIQUE

بعضی ستون‌ها شناسه نیستند ولی باز نباید تکراری باشند؛ مثل ایمیل که هر کاربر یکی دارد. قید UNIQUE تکراری‌بودن را ممنوع می‌کند ولی برخلاف کلید اصلی، در یک جدول می‌شود چندتایش داشت.

ویژگی PRIMARY KEY UNIQUE
تعداد در هر جدول فقط یکی چندتا مجاز است
مقدار NULL ممنوع مجاز (در MySQL چند NULL هم مجاز است)
مثال ما CustomerID ستون ایمیل (در ادامه)

افزودن ستون ایمیل یکتا

ستون ایمیل را با قید یکتایی به جدول اضافه می‌کنیم و برای ۵ مشتری موجود ایمیل می‌گذاریم:

query.sql
ALTER TABLE Customers
  ADD Email VARCHAR(100) UNIQUE;
query.sql
UPDATE Customers SET Email = 'sara@test.com' WHERE CustomerID = 1;
UPDATE Customers SET Email = 'reza@test.com' WHERE CustomerID = 2;
UPDATE Customers SET Email = 'maryam@test.com' WHERE CustomerID = 3;
UPDATE Customers SET Email = 'ali@test.com' WHERE CustomerID = 4;
UPDATE Customers SET Email = 'zahra@test.com' WHERE CustomerID = 5;

تست محافظت: ایمیل تکراری

query.sql
-- خطا می‌دهد؛ این ایمیل قبلاً برای سارا ثبت شده است
UPDATE Customers SET Email = 'sara@test.com' WHERE CustomerID = 2;

خطای Duplicate entry 'sara@test.com' for key 'Email' می‌گیرید و ایمیل رضا عوض نمی‌شود. از این به بعد ستون Email پنجمین ستون ثابت جدول ماست و در مثال‌های بعدی هم هست.

نکته: نام ستون‌ها در خروجی SELECT * از این به بعد شامل Email هم می‌شود. اگر مثالی فقط ۴ ستون نشان داد، خودش ستون‌ها را نام برده است.
