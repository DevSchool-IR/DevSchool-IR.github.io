MySQL Workbench

MySQL Workbench ابزار رسمی و رایگان MySQL است که به‌جای صفحه‌ی سیاه ترمینال، یک محیط گرافیکی برای نوشتن کوئری، دیدن جدول‌ها و مدیریت سرور به شما می‌دهد. تقریباً همه‌ی تمرین‌های این دوره را می‌توانید داخل همین ابزار انجام دهید.

نصب Workbench

اگر موقع نصب در فصل قبل گزینه‌ی Developer Default را زده باشید، Workbench همراهش نصب شده است. وگرنه از صفحه‌ی دانلود MySQL فایل MySQL Workbench را جدا بگیرید و نصب کنید. بعد از اجرا، صفحه‌ی اولش لیست اتصال‌ها را نشان می‌دهد.

اولین اتصال به سرور

  • روی کاشی خاکستری Local instance MySQL کلیک کنید.
  • رمز کاربر root را که موقع نصب ساختید وارد کنید.
  • اگر تیک Save password in vault را بزنید، دفعات بعد رمز نمی‌خواهد.
نکته: اگر موقع اتصال خطای Cannot Connect to Database Server گرفتید، یعنی سرویس MySQL خاموش است. اول از فصل ۲ سرویس را روشن کنید و بعد دوباره امتحان کنید.

بخش‌های مهم صفحه

بخش کاربرد
Navigator (ستون چپ) لیست دیتابیس‌ها و جدول‌ها
Query Tab (وسط) جایی که کوئری را می‌نویسید
Result Grid (پایین) نتیجه‌ی اجرای کوئری
دکمه‌ی صاعقه Execute اجرای کوئری نوشته‌شده

اجرای اولین کوئری در Workbench

در زبانه‌ی کوئری این دستور را بنویسید و دکمه‌ی صاعقه را بزنید:

query.sql
SELECT 1 + 1;

در جدول پایین باید عدد 2 را ببینید. این یعنی اتصال سالم است و سرور جواب می‌دهد. حالا نسخه‌ی سرور را هم ببینید:

query.sql
SELECT VERSION();

دیدن دیتابیس‌های آماده

این دستور لیست همه‌ی دیتابیس‌های روی سرور را نشان می‌دهد:

query.sql
SHOW DATABASES;

چند دیتابیس سیستمی مثل information_schema و mysql را می‌بینید. به این‌ها دست نزنید؛ دیتابیس تمرینی خودمان را در فصل ۹ می‌سازیم.

ذخیره‌ی اسکریپت

از منوی File گزینه‌ی Save Script را بزنید و فایل را با پسوند .sql ذخیره کنید. این‌طوری تمرین‌هایتان را نگه می‌دارید و بعداً دوباره بازشان می‌کنید. پیشنهاد می‌کنم برای هر فصل یک فایل جدا مثل session03.sql بسازید.

نکته: کلید میانبر اجرای کوئری در Workbench دکمه‌های Ctrl + Enter است. اگر فقط بخشی از متن انتخاب شده باشد، فقط همان بخش اجرا می‌شود؛ وگرنه کل زبانه اجرا می‌شود.
