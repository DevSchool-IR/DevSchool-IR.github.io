فصل ۲۶ | SQL Joins

FULL OUTER JOIN

FULL OUTER JOIN همه‌ی رکوردهای هر دو جدول را برمی‌گرداند؛ هرجا تطبیق نباشد، سمتِ بدون تطبیق NULL می‌شود.

مثال پایه

query.sql
SELECT Customers.Name, Orders.OrderID
FROM Customers
FULL OUTER JOIN Orders ON Customers.CustomerID = Orders.CustomerID;
  • مشتری بدون سفارش → ستون OrderID اش NULL
  • سفارش بی‌مشتری → ستون Name اش NULL
  • رکوردهای جور (تطبیق‌یافته) → هر دو ستون پر

پیداکردن رکوردهای بدون تطبیق در هر دو طرف

query.sql
SELECT Customers.Name, Orders.OrderID
FROM Customers
FULL OUTER JOIN Orders ON Customers.CustomerID = Orders.CustomerID
WHERE Customers.CustomerID IS NULL
   OR Orders.OrderID IS NULL;
نکته: MySQL از FULL OUTER JOIN پشتیبانی نمی‌کند؛ در آن‌جا باید با ترکیب LEFT و RIGHT و UNION همین نتیجه را بسازید. این را در فصل ۲۸ می‌بینید.
