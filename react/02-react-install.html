نصب و راه‌اندازی

برای شروع کار با React به یک محیط توسعه نیاز داریم. مدرن‌ترین راه، استفاده از ابزار Vite است که سریع، سبک و استاندارد امروزی محسوب می‌شود. Vite با یک دستور پروژه را می‌سازد و سرور توسعه‌ی سرد (Hot Reload) را بالا می‌آورد.

پیش‌نیازها

تنها به Node.js نیاز دارید. بعد از نصب Node، npm هم به همراه آن نصب می‌شود. برای بررسی نصب بودن، دستورات زیر را اجرا کنید.

terminal
node -v

npm -v

ساخت پروژه با Vite

دستور زیر یک پروژه‌ی جدید با قالب React و زبان JavaScript می‌سازد. بعد از ساخت، وارد پوشه شوید و با npm install وابستگی‌ها را نصب کنید.

terminal
npm create vite@latest my-app -- --template react

cd my-app

npm install

npm run dev
نکته: Vite به‌صورت پیش‌فرض پوشه‌ی src دارد و فایل اصلی ورودی src/main.jsx است. تغییرات با Hot Reload بلافاصله نمایش داده می‌شود.

ساختار پوشه‌های یک پروژه React

  • index.html — صفحه‌ی ورودی که React به آن متصل می‌شود
  • src/main.jsx — نقطه‌ی شروع؛ کامپوننت ریشه را رندر می‌کند
  • src/App.jsx — کامپوننت اصلی برنامه
  • package.json — وابستگی‌ها و اسکریپت‌ها

جمع‌بندی

با چند دستور ساده پروژه‌ی React با Vite ساخته و اجرا می‌شود. در فصل بعد با JSX، زبان ساختاردهی رابط کاربری در React، آشنا می‌شویم.
