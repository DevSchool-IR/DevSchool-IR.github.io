useRef

useRef یک جعبه‌ی قابل تغییر می‌سازد که بین رندرها زنده می‌ماند؛ برخلاف useState، تغییر دادن مقدار ref باعث رندر مجدد نمی‌شود. کاربرد اصلی آن دسترسی مستقیم به عناصر DOM (مثل input) و نگه‌داشتن مقادیری است که نباید رندر را تحریک کنند.

دسترسی به DOM

با prop به نام ref می‌توانیم یک ref را به عنصر DOM وصل کنیم و بعد از mount به متدهای آن دسترسی داشته باشیم. در این مثال وقتی صفحه باز می‌شود، input به‌صورت خودکار فوکوس می‌گیرد:

LoginForm.jsx
import { useRef, useEffect } from "react";



function LoginForm() {

  const inputRef = useRef(null);



  useEffect(() => {

    inputRef.current?.focus();

  }, []);



  return <input ref={inputRef} placeholder="ایمیل" />;

}

ذخیره مقدار بدون رندر مجدد

اگر داده‌ای باید بین رندرها حفظ شود ولی تغییرش نباید UI را تازه کند، آن را در ref بگذارید.

Timer.jsx
function Timer() {

  const timerRef = useRef(null);



  const start = () => (timerRef.current = setInterval(() => console.log("تیک"), 1000));

  const stop = () => clearInterval(timerRef.current);



  return (

    <div>

      <button onClick={start}>شروع</button>

      <button onClick={stop}>توقف</button>

    </div>

  );

}

نگه‌داشتن مقدار قبلی state

یک ترفند رایج: ref به‌صورت خودکار روی مقدار قبلی است، چون بعد از هر رندر مقدار جدید را داخل آن می‌ریزیم:

PreviousCount.jsx
function PreviousCount() {

  const [count, setCount] = useState(0);

  const prevRef = useRef(count);



  useEffect(() => {

    prevRef.current = count;

  }, [count]);



  return (

    <p>

      قبلی: {prevRef.current} — فعلی: {count}

    </p>

  );

}
نکته: Ref ها مثل state نباید در زمان رندر خوانده/نوشته شوند (به‌جز initialization). خواندن ref در handler یا event مجاز است.

جمع‌بندی

useRef برای دسترسی به DOM و نگه‌داشتن مقادیر بین رندرها بدون تحریک رندر مجدد به‌کار می‌رود. در فصل بعد با Context برای عبور داده از میان درخت کامپوننت‌ها آشنا می‌شویم.
