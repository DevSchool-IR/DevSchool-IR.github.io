Inheritance

وراثت (Inheritance) یعنی یک کلاس (فرزند) می‌تواند اعضای کلاس دیگر (والد) را به‌ارث ببرد. با کلمه‌ی extends انجام می‌شود.

کلاس والد

Animal.java
public class Animal {
    String type = "Animal";

    void eat() {
        System.out.println("I can eat");
    }
}

کلاس فرزند با extends

Dog.java
public class Dog extends Animal {
    void bark() {
        System.out.println("Woof!");
    }
}
Main.java
Dog d = new Dog();
d.bark();
d.eat();

bark از خودِ Dog است و eat از Animal به‌ارث رسیده است.

کلمه‌ی super

Cat.java
public class Cat extends Animal {
    Cat() {
        super.type = "Cat";
    }
}

super به اعضای کلاس والد اشاره می‌کند، مثل this که به خود شیء اشاره دارد.

Override کردن متد

Dog.java
public class Dog extends Animal {
    @Override
    void eat() {
        System.out.println("Dog is eating");
    }
}

با @Override رفتار متدِ ارث‌برده را عوض می‌کنیم.

نکته: یک کلاس فقط می‌تواند از یک کلاس ارث ببرد؛ برای چند رفتار، از Interfaceها در فصل ۴۲ استفاده می‌شود.
